群知 · 微信群助手

本地运行，多群答疑，按需联网，周报先预览。

1. 环境与安装2. 先运行本地工作台3. 接入群历史4. 配置后台发送5. 日常使用6. 引用图片7. 周报8. 排错9. 数据与依赖

1. 环境与安装

需要 Windows 10/11 x64、Python 3.12 x64、Git、已登录的本人微信账号，以及支持 /chat/completions 的模型 API。图片答疑需要模型支持 image_url。联网搜索另需能访问公开搜索引擎；无需额外搜索 API Key，但可用性不保证。

git clone https://github.com/KingRainIce/wechat-group-assistant.git
cd wechat-group-assistant
powershell -ExecutionPolicy Bypass -File setup.ps1

setup.ps1 创建独立 .venv、安装固定 Python 依赖，并下载下面列出的固定版本第三方源码。不会配置账号、启动发送或上传聊天记录。建议放在本地非共享目录。安装失败时先检查 Python 版本和网络，再重跑。

2. 先运行本地工作台

.\.venv\Scripts\python.exe app.py

访问 http://127.0.0.1:8765。连接设置中填写自己的 API Base URL（通常以 /v1 结尾）、API Key 和模型名。点击保存、测试连接。原实例使用 gpt-6.1-sol；新用户应填服务商实际支持的模型名。示例地址 api.example.com 不是真实服务。

先保持后台暂停、发送关闭。在“群与数据”修改示例群或新增群，填写完整群名。每个群单独启用、单独控制 @ 答疑。群内历史检索不会跨群。

3. 接入群历史

微信登录后，使用只读本地接入脚本。脚本读取当前账号所需密钥并用 Windows DPAPI 保存，不显示密钥，也不改写源数据库。

.\.venv\Scripts\python.exe setup_local_data.py

若存在多个账号目录或使用自定义存储路径，明确指定目标账号目录：

.\.venv\Scripts\python.exe setup_local_data.py --db-storage "D:\WeChatData\your-account\db_storage"

失败时不会自动换用其他提取方式。确保微信正在运行、只有目标客户端、路径下有 contact/contact.db。密钥提取依赖上游实现，客户端版本变化可能失效。

在工作台点击“同步历史”，核对群名、记录数量和时间范围。唯一群名可自动匹配；重名时须填写该群准确的稳定 ID（以 @chatroom 结尾）。机器人账号 ID 会在本地同步时自动保存；若使用备用数据服务，需手动填写当前登录账号的 wxid。

本地入口优先，备用 WeChatDataAnalysis 服务默认 127.0.0.1:10392；“发现群”依赖该备用服务。也可导入 UTF-8 JSON，仅用于本地检索，不触发历史补发：

[{"id":"example-1","timestamp":"2026-01-01T09:00:00+08:00","sender":"成员甲","sender_id":"demo-user","text":"周五开会","is_self":false,"mentions":[]}]

4. 配置后台发送

此部分仅适配微信 4.1.10.27 x64。4.1.9.55 不能直接套用，其他版本未经验证。仓库不提供客户端或 DLL 下载包。自行从可信来源准备有合法使用权的完整客户端，保留原安装与数据备份，将完整运行目录复制为：

private/client-4.1.10.27/runtime/Weixin.exe
private/client-4.1.10.27/runtime/4.1.10.27/Weixin.dll
private/client-4.1.10.27/runtime/4.1.10.27/VoipEngine.dll

保留客户端目录内其他文件。准备 x86_64 LLVM-MinGW 编译器，生成并编译最小文本发送桥：

.\.venv\Scripts\python.exe prepare_bridge.py
powershell -ExecutionPolicy Bypass -File native_bridge/build.ps1 -Compiler "D:\llvm-mingw\bin\clang++.exe"

检查 native_bridge/version.dll 已生成。退出准备接入的微信后，将它复制到上述 runtime 目录、与 Weixin.exe 同级；若已有同名文件先备份，禁止盲目覆盖。然后双击“启动后台微信.cmd”并完成登录。该启动入口传入本机认证信息，直接双击 Weixin.exe 不会完成同样的初始化。

工作台选择“后台发送”，勾选同步和目标群的 @ 答疑，再点击“启动后台任务”。本地模块只监听 127.0.0.1:30001，校验令牌、客户端版本与群白名单。没有连接时保持等待，不会自动占用前台键鼠。

要停用后台桥，退出该兼容客户端后，将自己添加的 version.dll 移出 runtime；不要删除原始客户端文件。正常停止助手不会退出微信。

5. 日常使用

  • 双击“启动群助手.cmd”；双击“停止群助手.cmd”停止服务。关闭浏览器不停止服务。
  • 从群成员列表选择机器人并真实 @ 提问；复制“@昵称”文字不会触发。
  • 所有成员均可提问；回复发回提问群，纯文本，允许少量 emoji，不带编号引用或末尾依据。
  • 开启联网查询后，未知模型、产品和时效信息按需检索；普通代码、数学和写作可直接回答。检索失败会明确说明。
  • 多个群共用模型和联网设置，各自控制收录及回复。电脑和微信需持续运行且已登录，不要求打开目标聊天窗口。
  • 数据库变更触发同步，另有 30 秒补查；发送队列每 5 秒检查。模型、检索和数据同步均会增加延迟，没有固定秒回保证。
  • 只处理启用之后、最近 10 分钟内的新 @。每群每分钟最多生成 3 条回复，超限消息目前不自动补发。

6. 引用图片

先完成历史接入，并在微信中打开近期原图，使原图缓存到本机。运行：

.\.venv\Scripts\python.exe setup_images.py

在群里引用一张图片，同时从成员列表 @ 机器人提问。程序按引用消息 ID 在同一群定位本地图片，解密后交给视觉模型。原图未下载、密钥未取得或格式不支持时会提示失败；只有缩略图时会说明。WXGF 解码依赖上述兼容客户端的 VoipEngine.dll。

不支持历史图片批量索引、语音识别、视频理解和附件正文解析。

7. 周报

在“群聊周报”选择群和起止日期生成预览，结束日期包含当天。默认每周一北京时间 09:00 后生成上周预览，可在连接设置修改日期与时间。程序需运行且后台未暂停；错过当天不会保证跨日补生成。已有周期报告不会重复生成。

当前版本没有启用定时发群，接口也拒绝开启 weekly_send。需要分享时自行复制审核后的内容到微信。

8. 排错

现象检查
@ 后无回复确认真实 @ 元数据、群启用和答疑开关、后台未暂停、监听无错误。机器人自己发的消息不会触发。旧消息、超限消息不会补发。
有草稿但未发送确认后台发送已选、桥接状态已连接、微信版本正确、稳定群 ID 已绑定。uncertain 表示结果不确定，先人工核对原群，不要重复发送。
联网失败检查模型规划请求与搜索网络。后台已强制 UTF-8；搜索引擎无结果、限流或超时仍可能失败。
找不到历史答案核对收录时间范围和同步结果。检索基于中文关键词及邻近上下文，尚无向量检索，可能漏检。
端口被占用先停止旧助手。本机已有运行实例时，不要启动第二份来读写同一数据。
图片无法解码打开原图、重新运行 setup_images.py，确认模型支持图片且客户端解码库路径正确。

查看工作台最近活动，或 private/server-error.log。诊断脚本：

.\.venv\Scripts\python.exe check_runtime.py
.\.venv\Scripts\python.exe -m pytest -q

测试使用隔离数据和模拟发送，不向微信群发消息。发布时本地测试通过不代表已在另一台全新机器完成安装验证。

9. 数据与依赖

private/ 保存配置、消息索引、队列、日志及 DPAPI 密钥。DPAPI 通常只允许本机当前 Windows 用户解密，换电脑应重新配置；备份整个 private/ 时按敏感数据保管。仓库默认忽略它，禁止提交真实数据库、图片、群 ID 或密钥。

答疑会将问题与相关群消息片段发往所配置模型服务；引用图也会发往该服务。搜索规划只收到问题，检索按公开关键词执行并过滤部分敏感格式，这不是绝对的数据防泄漏保证。使用前应取得所需授权，并了解模型服务的数据处理方式。

第三方依赖不打包进仓库，也不据此宣称取得重新分发授权。使用与分发前应自行检查上游许可。生成的桥接代码及 DLL 默认忽略。

  • WeChatDataAnalysis：只读数据库与图片密钥工具，固定 aa10c0940813e3dd41aed98e3b27f4bd8999ac28。
  • WeChat-Hook：桥接生成所需实现和头文件，固定 a9d3f27e4afbe4af85ba72a0a9d93ef8f16e594f；仅生成文本发送部分。
  • Python 依赖和版本见 requirements.txt；微信客户端及其库由使用者自行提供。

本项目尚未指定开源许可证；公开可见不等于授予任意复用权。使用微信非官方内部接口存在兼容与账号风险，不能承诺不会被平台限制。
