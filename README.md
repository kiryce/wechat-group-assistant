# 群知 · 微信群助手

Windows 本地运行的微信群助手：群历史答疑、联网查询、引用图片识别、周报预览。

- 多群独立配置，所有成员真实 @ 可触发，回复原群。
- 后台发送仅适配微信 **4.1.10.27 x64**，不占用键鼠。
- 支持 Chat Completions 兼容接口；模型名由服务商提供。
- 默认暂停、关闭发送，周报不会自动发群。

## 开始

安装 Python 3.12 x64 和 Git，运行 `powershell -ExecutionPolicy Bypass -File setup.ps1`。

完整安装、微信接入、图片配置、使用与排错见 [使用说明](index.html)（下载后用浏览器打开）。

## 文件

应用模块位于根目录；`static/` 和 `templates/` 为界面，`native_bridge/` 为后台桥接源码，`tests/` 为测试。
`private/` 保存本机密钥和消息，`vendor/` 保存固定版本依赖，两者不会提交。

## 边界

这是依赖客户端内部实现的实验性工具，并非微信官方接口；客户端更新可能失效，不能保证账号不受平台限制。请仅接入有权处理的群数据。相关消息片段和引用图片会发往你配置的模型服务。

不分发微信程序、聊天记录、凭据和第三方生成代码。第三方项目的许可与来源见使用说明。
