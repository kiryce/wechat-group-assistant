历史数据与定时任务

接入真实微信群

  1. 先验证模型。“连接设置”中使用 gpt-6.1-sol，点击测试连接。
  2. 准备历史数据。配置 WeChatDataAnalysis 的本机账号和历史读取服务，默认地址为 http://127.0.0.1:10392。完成 setup_local_data.py 后可使用本地只读入口；上方地址仅供备用。也可导入 JSON 记录。
  3. 绑定测试群。“群与数据”中点击“示例群”的同步历史，核对收录数量和时间范围，再用一条已知问题检查回答出处。
  4. 预览周报。选择日期范围生成，检查消息覆盖情况与结论。
  5. 自动回复接入。使用“启动后台微信.cmd”打开兼容客户端并登录，然后选择“后台发送”。按稳定群 ID 发送，不操作鼠标、键盘或当前聊天。入站由数据库变更通知触发，30秒补查；发送后核对原群记录，不确定时不重发。客户端版本变化会停止发送。

公开版本的历史工具与其收费高级版能力不同。本程序不购买服务、不绕过权限。电脑休眠或程序关闭时不会执行任务；恢复后在生成日补生成，已生成周报不会重复生成。

运行与停止

双击项目里的“启动群助手.cmd”启动，然后打开 http://127.0.0.1:8765。页面右上角可以暂停后台同步与定时任务；关闭网页不会关闭服务。双击“停止群助手.cmd”停止本项目服务。

当前能力边界

文字与链接可检索。支持在群里引用单张图片并真实 @机器人提问：按原消息 ID 读取同群本机图片，并发送至配置的模型中转站识别；没有大图时说明只取得缩略图，无法读取时明确提示。图片尚未批量建立历史索引；语音、附件正文尚未解析。问答使用本地中文关键词检索与邻近上下文，尚未启用向量语义检索；表述差异较大时可能漏检。时间表达支持上周、本周、昨天、今天、最近 N 天/周/月和 YYYY-MM-DD 日期；一个月按 30 天计算。

数据位于项目 private 目录，请勿放在共享或云同步目录。API 密钥仅能由本机当前 Windows 用户解密。程序只监听 127.0.0.1。
